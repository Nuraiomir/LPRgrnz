ИНСТРУКЦИЯ ПО ЗАПУСКУ LPR OCRM PoC

1. СКАЧИВАНИЕ ПРОЕКТА

Проект размещён в приватном GitHub-репозитории:
https://github.com/Nuraiomir/LPRgrnz

Для доступа необходимо получить приглашение от владельца репозитория и принять его.

После получения доступа:
1. Открыть репозиторий.
2. Нажать Code.
3. Выбрать Download ZIP.
4. Распаковать архив в удобную папку.

2. СТРУКТУРА ПРОЕКТА

Основные папки и файлы:

README.md
    Основная информация о проекте

3. ТРЕБОВАНИЯ

Для запуска необходимы:
- Windows
- Python 3
- камера для работы в режиме реального времени

Интернет необходим первоначально для установки Python-зависимостей.

4. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ

Открыть PowerShell в папке проекта и выполнить:

python -m venv .venv

Активировать окружение:

.\.venv\Scripts\Activate.ps1

После активации в начале строки PowerShell должно появиться (.venv).

5. УСТАНОВКА ЗАВИСИМОСТЕЙ

В активированном виртуальном окружении выполнить:

pip install -r requirements.txt

Установка может занять некоторое время.

6. ЗАПУСК ЛОКАЛЬНОГО OCRM BACKEND

Открыть первый PowerShell в папке проекта.

Активировать окружение:

.\.venv\Scripts\Activate.ps1

Запустить backend:

python .\app\ocrm_backend.py

Backend работает по адресу:

http://127.0.0.1:8000

Проверка:

Invoke-RestMethod http://127.0.0.1:8000/health

При успешном запуске должен вернуться статус backend и информация о локальной тестовой базе.

7. ЗАПУСК LPR STREAMLIT

Открыть второй PowerShell в папке проекта.

Активировать окружение:

.\.venv\Scripts\Activate.ps1

Запустить:

python -m streamlit run .\app\streamlit_live_ocrm.py

После запуска открыть в браузере:

http://localhost:8501

При запросе браузера необходимо разрешить доступ к камере.

8. КАК РАБОТАЕТ СИСТЕМА

Основной pipeline:

Camera
  ↓
WebRTC / Streamlit
  ↓
YOLO
  ↓
License Plate Detection
  ↓
OpenCV preprocessing
  ↓
PaddleOCR
  ↓
Normalization
  ↓
OCR Voting
  ↓
CONFIRMED
  ↓
Local OCRM API
  ↓
Vehicle information

Система обнаруживает ГРНЗ, распознаёт номер, подтверждает результат несколькими OCR readings и выполняет поиск номера в локальной тестовой базе OCRM.

Если номер найден — отображается информация об автомобиле.

Если номер успешно распознан, но отсутствует в локальной базе — система показывает, что автомобиль не найден в базе OCRM.

11. ВАЖНОЕ ЗАМЕЧАНИЕ

Текущий OCRM backend является локальной тестовой реализацией.

Он НЕ подключён к реальной производственной базе OCRM БУК.

Текущая архитектура PoC предназначена для демонстрации и тестирования pipeline LPR.

В будущем локальный backend может быть заменён реальным API OCRM.
